# Oracle PL/SQL - Exemplos para Estudo

Este repositório foi criado com o objetivo de centralizar e organizar exemplos práticos de **Oracle PL/SQL**. Ele serve como um guia de referência rápida para comandos essenciais e boas práticas durante o processo de estudo e desenvolvimento.

## Propósito

O foco aqui é fornecer scripts simples e funcionais que abrangem desde a manipulação de estrutura de dados (DDL) até o controle de acesso (DCL) e manipulação de informações (DML).

## Estrutura do Repositório

O projeto está organizado por categorias de comandos:

* **`/ddl`**: Exemplos de *Data Definition Language*.
    * `/create`: Criação de tabelas e objetos.
    * `/modify`: Alteração de estrutura (`ALTER`, `DROP` de colunas, `TRUNCATE`).
* **`/dcl`**: Exemplos de *Data Control Language* (`GRANT`, `REVOKE`).
* **`/dml`**: Exemplos de *Data Manipulation Language* (`INSERT`, `UPDATE`, `DELETE`).

## 🛠️ Como usar

Os scripts estão no formato `.sql` e podem ser executados em qualquer ferramenta de gerenciamento de banco de dados Oracle, como:
* SQL Developer
* SQLcl
* DBeaver
* Oracle XE (Express Edition)
